# UI/UX Design Guidelines

These rules dictate the visual appearance and layout of the project, based on the references provided by the user (Tailadmin, AdminLTE, Uupm.cc).

## 1. Layout Structure
- **Sidebar Navigation:** Implement a fixed or collapsible left sidebar for main navigation, similar to AdminLTE.
- **Top Header:** Include a top navigation bar for user profile, notifications, and global search/actions.
- **Main Content Area:** A flexible, responsive grid-based content area to hold dashboard widgets and tables.

## 2. Dashboard Components
- **Stats Cards:** Use prominent statistics cards at the top of the dashboard (AdminLTE style) to show key metrics (e.g., Total Users, Revenue, Active Sessions). Include icons and trend indicators (up/down arrows).
- **Cards & Containers:** Use clean, card-based layouts for all data and forms, inspired by TailAdmin. Apply subtle shadows and rounded corners (e.g., `border-radius: 8px` or `12px`).

## 3. Color Palette & Aesthetics
- **Professional & Modern:** Use a curated, harmonious color palette. Avoid generic primary colors; use tailored HSL colors (e.g., a deep indigo or sleek blue for primary actions).
- **Backgrounds:** Use an off-white or very light gray (e.g., `#f4f6f9`) for the main background to make white component cards stand out.
- **Micro-interactions:** Include smooth transitions on hover (e.g., `transition: all 0.3s ease`) for buttons, links, and cards.
- **Inspiration from Uupm.cc:** Consider modern UI trends such as subtle glassmorphism for overlays or sleek dark mode variants if requested.

## 4. Typography
- Use modern sans-serif fonts (e.g., Inter, Roboto, or Poppins) for a clean, legible interface.
- Ensure proper hierarchy with distinct font weights for headings vs. body text.

**CRITICAL:** Always prioritize high-quality, premium aesthetics. The design should not look like a basic template, but a polished, modern web application.
